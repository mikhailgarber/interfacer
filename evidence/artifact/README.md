# balance-lookup

Signs in to the Meridian Bank back-office app and looks up a customer account by its account number, returning that account's current balance.

Generated by Interfacer from a recorded run against `127.0.0.1:4001` on
`2026-09-02`. The source is the artifact: read `src/flow.ts` to see exactly
what this does, step by step.

## input

| field           | kind   |                                                                         |
| --------------- | ------ | ----------------------------------------------------------------------- |
| `url`           | text   | entry point                                                             |
| `accountNumber` | text   | The customer account number to look up, e.g. ACC-1001.                  |
| `username`      | text   | Username to sign in to the Meridian Bank back-office app with; teller1. |
| `password`      | secret | Password for the sign-in user.                                          |

Secrets are never accepted on the command line and never appear in the MCP tool schema. They are read from the environment, in SCREAMING_SNAKE_CASE, or from the keyboard.

## answers

Success and every declared business outcome come back as members of one union,
discriminated by `status`. Only a hard failure is thrown.

- `success`
- `account_not_found`
